5. AI API 연동 (선택)

저장된 키가 없습니다. 키는 서버로 전송되지 않고 이 브라우저의 localStorage에만 저장되며, 실제 API 호출은 사용자의 브라우저에서 직접 발생합니다.

6. 전략 목록

전략 함수 작성 가이드 보기 함수 시그니처: function strategy(context)

context 입력:
• context.current — 현재 캔들 {date, open, high, low, close, volume}
• context.history — 지금까지의 전체 과거 캔들 배열 (지표는 직접 계산)
• context.index — 현재 캔들 인덱스
• context.portfolio — {cash, shares, avgPrice, totalValue}
• context.news — {mode, stage, sentiment, raw}
  stage: "BOOM" | "LIGHT_BOOM" | "NONE" | "LIGHT_DOWNTURN" | "DOWNTURN" | "FAILURE"

반환 (출력) 형식:
• { action: "BUY", amount: 10 }
• { action: "SELL", amount: "ALL" }
• { action: "HOLD" }

현금/보유 부족 등 유효하지 않은 주문은 엔진이 자동으로 HOLD 처리합니다.
